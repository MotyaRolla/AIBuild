# RECIPE: tower / lighthouse / wizard tower / spire
- Silhouette: tall and slender (height 3-6x the width), slight taper or stepped stages, an exciting crown
  (overhanging roof, spire, onion, balcony ring, lantern room, floating crystals for magic).
- Stages: plinth with flare -> shaft with windows climbing in a spiral -> corbelled belt course(s) -> top stage
  wider than the shaft -> roof with overhang and finial. Break the shaft with string courses every 6-8 blocks.
- Craft: graded weathered masonry, deep window recesses with sills, buttresses or ribs on large towers,
  spiralStair() inside, balconies on brackets (upside-down stairs). Floors inside every 5-6 blocks, each
  furnished (furnish(..., 'study'|'library'|'bedroom'|'storage')); keep the stair column clear.
- Magic/wizard: purple/blue accent glass, amethyst, end rods, chains, a telescope or bookshelves at the top.
- Setting: a rock or hill base (rock(), terrain()), path, small outbuildings, trees, lampPost()s.
